# PF Platform — Monthly Owner Review Checklist

**For:** Brad (CEO / platform owner)
**Run with:** Peter (COO), monthly, ~15-20 minutes
**Purpose:** A simple owner-level review to keep the internal platform trustworthy, secure, and useful. Peter prepares the answers in advance; Brad reviews and decides.

> CEO-level view. Engineering detail lives in the other DevOps docs (RELEASE-PROTOCOL, LOGGING-MONITORING, MAINTENANCE-SUPPORT). Brad checks outcomes, not internals.

---

## 1. Access & Security
- [ ] User roster correct, right people and roles; anyone to add or remove?
- [ ] Login audit review, anything odd (failed/off-hours/unknown logins)?
- [ ] Any access issues reported (lockouts, wrong-area access)?
- [ ] Monthly security check done, any findings?

## 2. Data Accuracy & Trust
- [ ] Spot-check key data vs reality (bid log, project values, financials), does it match?
- [ ] SharePoint sync current, nothing stale?
- [ ] Any data users flagged as wrong, and fix status?

## 3. Backups & Recoverability
- [ ] A recent D1 backup exists this month?
- [ ] Could we actually restore if needed?

## 4. Platform Health & Usage
- [ ] Site up, gate holding, health green?
- [ ] Any outages or errors, and what was done?
- [ ] Is the team actually using it, which modules, which ignored?
- [ ] Open bugs/issues and their status.

## 5. Releases & Changes
- [ ] Review the month's changelog, anything needing your sign-off?
- [ ] Next month's roadmap and your priorities.
- [ ] Which "Coming in a later release" modules are ready to turn on.

## 6. Docs & Onboarding
- [ ] Manual and training current with the platform?
- [ ] New modules needing docs? Anyone needing training?

## 7. Cost & External Accounts
- [ ] Third-party costs (Cloudflare, added services) tracking as expected.
- [ ] Pending permission requests needing your decision (OneNote, transcripts, etc.).

## 8. Adoption & Feedback
- [ ] Is the team finding it useful, friction points?
- [ ] The one thing to improve next month.

---

### How Peter prepares
Before each review Peter pulls: the login/audit log, a data spot-check, backup confirmation, health-check results, the changelog, open issues, and pending decisions, so the review is "confirm and decide," not fact-finding. Peter also emails Brad a monthly reminder to run this review.

*Owner: Peter (COO). Cadence: monthly. Created 2026-06-23.*
