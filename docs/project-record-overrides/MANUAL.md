# Manual — Editing a Project Record

## Who can edit
Office staff (Brad, Jonathan, Derek and other admin/partner/business_dev users).
Field crew (field_ops) can view records but see no Edit buttons and cannot save.

## How to edit a section
1. Open a project from **Active Projects** (click the number or project name).
2. Each section (General Info, PF Team, Contract Info, Engineering & Design,
   Project Safety, Site Readiness, Equipment, Material, QA/QC, Financials,
   Project Closeout) has an **Edit** button on the right of its header.
3. Click **Edit**. The section's fields become text boxes.
4. Type/change any values. To add a field the record does not have yet, use the
   "New field name" + "Value" row at the bottom of the editor.
5. Click **Save**. The section re-draws with your values; each edited field shows
   a small ✎ and the header notes who last edited it and when.
6. Click **Cancel** to discard your changes and restore the section.

## What "manual override" means
Anything you save here WINS over the automatically synced data — and keeps
winning even after the next data sync. Your entries are saved for the whole
office (everyone sees them). If you want to blank a field, clear it and Save.

## New projects
A project created from an award/estimating handoff opens in this same editable
view with mostly blank fields — fill them in section by section using Edit.

## If a save fails
If the server can't save (e.g. connection issue), you'll see a red error and the
editor stays open with your text intact so you can retry. The platform will never
tell you it saved when it did not.
