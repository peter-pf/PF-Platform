## What I Learned
- project-records.js is AUTO-GENERATED by sync/build-project-records.py. Editing it by hand
  works for working-tree changes, but a future regen could drop the analysis blocks unless the
  generator is taught to carry them. FLAG for Brad if this needs to persist across syncs.
- Verdict is NOT a field in the standalone tool — it is implied by the presence of RED risk
  items. I set it explicitly (YELLOW for Shiel since it has no RED items; RED for the other two).
- Field-view safety came for free: the fo-projects renderer is a different function that never
  reads D.analysis. Confirmed by grep over the field-view region (lines 2117-2700): zero matches.
